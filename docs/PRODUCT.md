# Продукт — видение и принятые решения

_Обновлено: 2026-10-01. Источник истины по «зачем» и «как не сбиться с курса». Открытые задачи — в [BACKLOG.md](BACKLOG.md)._

## Мантра

**«Это не каталог мест. Это живой персональный гид для родителей: события + места + память пользователя + комьюнити + умная выдача.»**

Философия: **«Контент + поведение пользователя > отзывы».** Ценность — в поведении (♡ нравится, ✓ были здесь, «не интересно» = исключить категорию), а не в рейтингах. Сила сигналов: были > нравится > просмотр. Отзывы и рейтинги сознательно отложены.

### ⚠️ Анти-вектор

Если проект скатывается в «просто каталог мест» — без событий, без персонализации, без живого обновления данных, с обязательной привязкой события к месту — это сигнал «пошли не туда». Остановиться и сказать вслух.

**Беречь задумку, не уводить в generic.** Стандартное решение предлагать, только если оно служит видению. Если «best practice» конфликтует с ядром — назвать конфликт явно. Вкусовые решения (тексты, нейминг, визуал) — предложить и спросить, а не выбрать молча.

## Для кого

- Русскоязычные родители в Паттайе — ядро; дальше англоязычные, тайцы, китайцы (локали ru/en/th уже есть).
- **Комфортно обоим родителям — маме И папе.** Осознанная отстройка от мам-центричных конкурентов.
- Масштаб: платформа семейных гидов на много городов и стран; наполнение начинаем с Паттайи. Подробно — [MULTIREGION_PLAN.md](MULTIREGION_PLAN.md).

## Боли, которые закрываем

- «Открыто с утра» — малыши встают рано, а большинство мест открывается к 10–11.
- «Можно поработать» — родитель на удалёнке: Wi-Fi + кондиционер + где сесть.
- «Спрятаться от жары» — укрытие сверху И охлаждение (не только «в помещении»).
- «Пойти прямо сейчас» — что открыто в эту минуту.
- Дни рождения — прозрачные условия, что входит.
- Тайская цена vs цена для иностранцев — где есть и какой документ нужен.
- Временные события — «что происходит в эти выходные».

## Продукт двухосевой

- **«Куда пойти»** — места, спонтанно (статус «открыто сейчас», сценарии).
- **«Чем заниматься»** — занятия и лагеря, планово (лента «Занятия», своя страница у занятия).
- Один источник данных — несколько входов: занятие видно и в карточке места, и в ленте, и на своей странице. Занятие может проходить без каталожного места (развивашки в садах — текстовое «место проведения»).

## Ключевые решения (не пересматривать без обсуждения)

- **Посадочная = «выдох», не каталог.** Один вопрос «Что ищете прямо сейчас?» + 3 живых сценария, меняются по времени суток; «показать другие»; ниже — карта. Каталог мест живёт на `/places`. Line-art иконки, не эмоджи (эмоджи дают ощущение «очередного мессенджера»).
- **Редкое, но ценное не прячем.** Сценарий на посадочной обычно требует 3+ мест, но «Открыто с утра», «Можно поработать» и «Спрятаться от жары» показываем уже с одним: таких мест может быть всего пара, и именно они нужнее всего.
- **Честный статус.** «Сегодня закрыто» видно и в списке; закрытая карточка приглушена, но не спрятана. Живой бейдж «Закроется через N мин». Недооценка безопаснее переоценки (доверие).
- **«Неизвестно» ≠ «нет».** Факты места — три состояния: есть / точно нет / уточняется (тихий курсив). `npm run gaps` — чек-лист пробелов в данных.
- **Источник + дата проверки** у спорных фактов (цены, тайская цена, ДР, советы «Полезно знать») — подпись «проверено: месяц год».
- **«Полезно знать»** — микро-детали из родительских чатов (носки, сменка, залог) — это ценность, а не мелочь.
- **Прошедшие события не удаляются** (архив, SEO, доверие); на карту не выводятся — только в списке.
- **indoor и outdoor — независимые признаки:** место может быть и крытым, и уличным.
- **Возраст `?age` сквозной** — остаётся в URL на всех страницах (новый посетитель тыкает всё подряд; сброс возраста = разочарование). Не «чинить».
- **Сети мест** (Skippy Land, Pa Boon, Little Gym) — пока каждая точка = отдельное место; модель бренда — потом.
- **Память родителя без регистрации** — ♡ «Нравится» и ✓ «Были здесь» в браузере; один вход ♡✓ в шапке.
- **Telegram-бот — канал возврата** (утро/выходные/события), не копия сайта. Ссылки с сайта — только `telegram.me`.
- **Форма «Предложить своё»:** не блокирует дубли, а подсказывает («Нет, это другое место» — филиалы сетей); для владельцев — подсказка, что карточка бесплатна.

## Дизайн: Calm-first

**«UI всегда тише контента».** Визуальный отдых родителя, без давления, взрослое гендерно-нейтральное пространство.

- Фон тёплый беж `#F1EAD8` (не белый), карточки белые, акцент — приглушённый sage дозированно.
- Запрещено: чистый чёрный, кислотные цвета, несколько зелёных на экране, зелёный фоном больших блоков, холодный белый/серый фон. **Один экран = один доминирующий тон + нейтраль.**
- Небольшие сдержанные фото в карточках; без витринных макетов и крупных доминирующих фото.
- Цвета и тени — только токенами, в обеих темах. **В тёмной теме глубину даёт светлота слоя, а не тень** (чёрная тень на тёмном не видна). Контролы держат контраст 3:1.

## Тон текстов

- Нейтрально к обоим родителям: «родители», «вы». ✅ «Куда пойти с ребёнком» ❌ «мамочкам на заметку», «ты записалась».
- Спокойно, тепло, без восклицательного маркетинга. Мягкие пустые состояния: «Место скоро опишем», «Дата уточняется».
- Три уровня языка: код — английский; подписи интерфейса — словари `src/content/{ru,en,th}.ts`; контент (названия, описания, категории) — в БД.
- Глоссарий: «Pattaya Kids Guide» не переводим; Indoor/Outdoor → «В помещении» / «На улице»; «Можно оставить ребёнка»; «Подробнее».
- Тайский — черновики помечать «на вычитку носителем».

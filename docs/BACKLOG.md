  - 3б — из предложения создавать событие и занятие (у события обязательна дата; у занятия черновик теперь есть — «Видимость: скрыто», 02.10). 🤖🎨

Обязательна пошаговая подсказка для нетехничных людей («откроется Telegram → нажмите „Старт“ внизу») и понятный ответ бота сразу. Только `telegram.me`. 🤖🎨
- **«Дополнить карточку»** — строки «Были здесь?» и «Это ваше место?» внизу карточек мест, событий и занятий ведут в короткую форму (текст, фото, «я представляю»); в админке это «дополнение к карточке», фото в галерею места переносятся кнопкой. Готово (01.10). Остаток:
  - «Полезно знать» у событий и занятий + поля «Полезно знать» в админке у мест, событий и занятий (рус + en) — готово (01.10). Перевод советов на en/th — пачкой: `npm run tips:export` → заполнить `scripts/tips/translations.json` (переводит Claude в сессии) → `npm run tips:apply`; `npm run gaps` напоминает о советах без перевода. 💻
  - **Автоперевод советов при сохранении в админке** — нажала «Сохранить», сайт сам запрашивает перевод у Claude API и заполняет en/th (заменит ручной шаг выше). Нужен платный ключ API — ждёт рабочей карты. 🤖
  - Фото из дополнения к событию или занятию ставится обложкой кнопкой под фото (у них одна картинка, галереи нет) — готово (01.10). Полей прав на изображение у события и занятия в схеме нет: пометка о правах не пишется — добавить поля, если понадобится. 🤖

## Продуктовые фичи

- **Дни рождения — большая перестройка блока** (детали ещё не проговорены — сначала обсудить). Часть: возраст на ДР должен **фильтровать**, но возраст ДР-формата ≠ возраст места (аквапарк подходит малышам как место, но не для их ДР) → своё поле возраста у ДР + ручной занос. Сейчас на `/birthdays` временная плашка «возраст здесь не фильтрует». 🎨
- **Личный кабинет** — не начат, срок не назначен. Возраст детей станет фактом профиля семьи. 🎨
- **«Можно оставить ребёнка» — двухуровневый бейдж** (возраст + контекст: игровая под присмотром ≠ занятие с родителем). Уровень класса уже решён таблицей классов. 🎨
- **Порядок блоков на странице места** — пересмотреть свежей головой (занятия не должны теряться под абонементами). 🎨
- **Модель сетей** (бренд, «сеть, N точек») — как показывать сеть родителю — продуктовый дизайн. 🎨
- **Лагеря** — сейчас в «Занятиях» как программы; вернуться к решению «событие или программа», когда лагерей станет больше. Идея: промо-блок «идёт запись в лагеря», который сам включается по датам. 🎨
  - **❓ На продумать (01.10): вынести лагеря на отдельную страницу?** Лагеря — регулярная штука, которая пользуется спросом у многих родителей. Отдельный раздел может быть удобнее и полезнее тем, кто ещё не знает, что лагеря вообще бывают: зайдут, увидят вариант — полезут смотреть. Внутри «Занятий» лагерь легко не заметить. Что взвесить: отдельный пункт навигации vs перегруз шапки; что показывать вне сезона (пустая страница или «прошедшие лагеря — ориентир на следующий год»); связь с промо-блоком выше; отдельный вход из поиска («летний лагерь Паттайя»). 🎨
- Фильтр-плитки категорий занятий на главной — включить при 8–10 занятиях. 🤖
- Язык персонала — фильтр отложен до появления данных. 🤖

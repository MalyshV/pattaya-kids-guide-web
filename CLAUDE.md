# Pattaya Kids Guide — правила для Claude

Гид для родителей: куда сходить с детьми в Паттайе (места, события, занятия, дни рождения). Next.js 16 + Prisma 7 (Postgres) + Vercel. Локали: ru / en / th.

**Прочитать перед работой:**
- [docs/PRODUCT.md](docs/PRODUCT.md) — видение, анти-вектор, принятые решения, дизайн и тон.
- [docs/BACKLOG.md](docs/BACKLOG.md) — открытые задачи (что можно делать в облаке, а что только локально или после обсуждения). Закрыл задачу — обнови бэклог в том же PR.

## Общение

- Отвечать **по-русски**, спокойно и по делу, без лишнего жаргона.
- Беречь задумку продукта: не сводить решения к «стандартному/generic». Если сомневаешься во вкусовом решении (текст, нейминг, визуал) — предложи и спроси, а не выбирай молча.

## Git и PR

- Ветку делать от свежего `main`, PR — в `main`.
- Один PR = одна логическая задача, маленькими шагами.
- **Коммиты и заголовки PR — Conventional Commits, тема по-русски:**
  `тип(область): что сделано`
  - типы: `feat`, `fix`, `refactor`, `style`, `test`, `docs`, `chore`
  - области по смыслу: `admin`, `suggest`, `places`, `events`, `ui`, `links`, `upload`, `db`…
  - примеры: `feat(suggest): фото в форме «Предложить своё»`, `fix(links): Telegram с сайта — telegram.me вместо t.me`, `chore(deps): генерировать Prisma-клиент после npm install`
- Описание PR — по-русски: что и зачем, как проверено.
- Перед коммитом: `npm run check` (lint + typecheck + vitest) должен быть зелёным.

## Код

- Слои: route → service → mapper → DTO. Обработчики тонкие, Prisma-модели наружу не отдавать.
- TypeScript strict, без `any`; читаемость важнее хитрости, без лишних абстракций.
- Новая чистая логика — с тестами vitest рядом с модулем (`*.test.ts`).
- Прошедшие события не удалять (архив/SEO/доверие).
- Ссылки на Telegram с сайта — только через `telegram.me` (`t.me` блокируется у тайских провайдеров).

## Дизайн и тексты

- Calm-first: «UI тише контента» — тёплый беж, белые карточки, приглушённый sage; без чистого чёрного и кислотных цветов. Цвета — только через токены, в обеих темах (светлой и тёмной).
- Тексты нейтральны к обоим родителям: «родители», «вы» — не «мамы».

## Окружение

- Секретов (`.env`) в облачных сессиях нет: без `DATABASE_URL` страницы с данными отдают 500 — это ожидаемо. Код, тесты и PR работают и так.
- Прод и боевую базу не трогать. Занос контента — скриптами, которые запускает владелец проекта у себя.
